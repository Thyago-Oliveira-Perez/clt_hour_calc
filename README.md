# 🕒 Cálculo de Jornada CLT

Este script em Python calcula o horário de saída necessário para completar uma jornada de 8 horas de trabalho, com base no horário de entrada e na duração do almoço.

## ✅ Requisitos

- Python 3.6 ou superior (já inclui a biblioteca `argparse`)

## 💻 Como usar

1. Clone ou baixe este repositório.
2. Salve o script como `calculo_jornada.py`.

3. No terminal, execute o comando:

```bash
python calculo_jornada.py <hora_entrada> <duracao_almoco>

ex:

python calculo_jornada.py 08:00 01:00
